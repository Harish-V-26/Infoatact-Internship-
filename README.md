## Repository conventions

- Each team member works on their own branch (`<name>-p1` / `<name>-p2`), merged via pull request — not committed directly to `main`.
- No real credentials, private keys, or PHI/PII are ever committed. See each project's `.gitignore` and `.env.example`.
- GitHub Issues track all outstanding work per project, assigned individually per person.
